## 💻 How to Run Locally (If Applicable)

If you've cloned this repository and want to run it locally (if you have a Node.js server setup):

1.  Clone the repository: `git clone https://github.com/sagarchauhansk/sagarchauhansk.github.io.git`
2.  Navigate to the directory: `cd sagarchauhansk.github.io`
3.  Install dependencies: `npm install`
4.  Start the server: `npm start`
5.  Open your browser and go to `http://localhost:3000`.
